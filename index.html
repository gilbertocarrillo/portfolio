Model layer

One interface, seven LLM providers

Built a model-agnostic LLM layer across OpenAI, Azure OpenAI, Anthropic, Gemini, DeepSeek, GLM and LG EXAONE, with retries, rate-limit failover and load balancing, so features could switch models through configuration. On top of it, built the platform's multi-model chat: SSE streaming, file attachments checked against each model's capabilities, web-search citations and per-message credit accounting. It later became the foundation for the agent experience.

Python · FastAPI · SSE · Multi-provider LLMs

Workflow engine

From a linear prompt queue to a DAG engine clients build on

Re-architected the workflow engine from a linear prompt queue into a JSON-defined DAG with parallel execution, LLM-evaluated conditional branches and map-reduce loops over documents, images, audio and video. Enterprise clients such as KOTRA and The Korea Times built their own workflows on it. It also powers two of the platform's most-used features: translation of documents up to 1,000 pages and transcription of long audio and video, both consistent across chunks and resumable after failures.

Python · FastAPI · DAG · Map-reduce · OCR · Chunking

Knowledge

RAG knowledge bases and an LLM wiki

Also built the platform's document drive, where files, archived chats and workflow outputs are stored, summarized and reused as input in chats, agents and workflows.
